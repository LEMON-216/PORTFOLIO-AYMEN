# Portfolio Aymen Chaabane

Portfolio personnel d'Aymen Chaabane, chef de projet digital et développeur web.

## Stack technique

- HTML5 / CSS3 / JavaScript vanilla
- Polices : Arelv (titres), Satoshi (corps)
- Multilingue : FR / EN / AR / JA
- Animations : starfield Canvas, scroll reveal, cursor custom

## Structure des fichiers

```
PORTFOLIO/
├── index.html          → Page d'accueil
├── projets.html        → Liste des projets
├── a-propos.html       → Présentation & CV
├── contact.html        → Formulaire de contact
├── 404.html            → Page d'erreur
└── public/
    ├── css/style.css
    ├── js/
    │   ├── translations.js   → Traductions des textes
    │   ├── lang.js           → Gestionnaire de langue
    │   └── script.js         → Animations & interactions
    ├── favicon/        → Icônes du site
    ├── logo/           → Logo principal
    ├── font/           → Polices Arelv et Satoshi
    ├── docs/           → CV téléchargeables
    └── photo/          → Images des projets

```

## Déploiement Netlify

Le site est entièrement statique, prêt à être déployé sur Netlify par glisser-déposer ou via Git.
